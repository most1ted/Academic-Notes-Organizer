## 📖 About

Managing scattered notes and files across a semester is painful. This project solves that by giving each student a personal academic archive — create courses, attach notes and files to them, and browse everything in one clean interface.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔐 **User Accounts** | Registration & login with Django's authentication |
| 📖 **Course Management** | Create, edit, and delete your courses |
| 📝 **Notes** | Write and organize your lecture notes with ease |
| 📎 **File Uploads** | Attach PDFs, images, and documents to your notes |
| 🔍 **Full-Text Search** | Search across note titles and content instantly |
| 📊 **Dashboard** | Personal overview with advanced filtering |
| 🐘 **PostgreSQL** | Production-grade database |
| 🐳 **Dockerized** | Run the entire stack with one command |
